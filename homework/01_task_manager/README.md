# Домашнее задание

## Список задач на Python с сохранением в JSON

Разработать небольшой проект с подробным описанием на выбранном языке программирования. Использовать особенности парадигмы и основные конструкции языка, установить интерпретатор и среду разработки, подробно комментировать код проекта.

Вариант: 17, где он предусмотрен заданием.

Источник: https://github.com/ugapanyuk/courses_content/wiki/DZ

Python 3.10 или новее. Установите зависимости из корневого requirements.txt.

## Запуск из этой папки

```bash
python main.py --file demo_tasks.json list
python main.py --file demo_tasks.json add 'Выполнить лабораторную 1'
python main.py --file demo_tasks.json add 'Подготовить отчёт'
python main.py --file demo_tasks.json done 1
python main.py --file demo_tasks.json list
python -m unittest discover -v
```

Проект использует процедурный подход, функции, списки, словари, генераторное выражение, контекстный менеджер файлов, исключения и argparse. Команды add, list и done добавляют, показывают и завершают задачи. Все данные сохраняются в JSON. Параметр --file позволяет выбрать отдельное хранилище.

## Результаты

Созданы две задачи, первая отмечена выполненной; данные читаются при следующих запусках. Три теста проверяют добавление, изменение состояния, сохранение и ошибочные команды. Исходное условие ДЗ требует ранее не изучавшийся студентом язык; здесь выбран Python согласно указанию пользователя. Установка IDE на личном компьютере студента не выполнялась.
