# Лабораторная работа 7

## Telegram бот на основе конечного автомата

Разработать Telegram бота, реализующего конечный автомат из трёх состояний.

Вариант: 17, где он предусмотрен заданием.

Источник: https://github.com/ugapanyuk/BKIT_2021/wiki/lab_bot2

Python 3.10 или новее. Установите зависимости из корневого requirements.txt.

## Запуск из этой папки

```bash
python main.py --demo
python -m unittest discover -v
```

Бот собирает имя и группу и предлагает подтвердить данные. Ровно три состояния: NAME, GROUP и CONFIRM. После Да или Нет автомат возвращается в NAME. Команды /start и /cancel очищают текущий ввод. Сессии независимы для пары chat_id и user_id; данные существуют только в памяти процесса.

## Запуск в Telegram

Создайте бота через @BotFather и сохраните токен только в переменной окружения.

Linux/macOS: `export TELEGRAM_BOT_TOKEN="ваш_токен"`

PowerShell: `$env:TELEGRAM_BOT_TOKEN="ваш_токен"`

Затем выполните `python main.py`. Остановка: Ctrl+C. Одновременно запускайте только один процесс с одним токеном; для двух лабораторных используйте разных ботов или запускайте по очереди. Режим getUpdates требует отсутствия активного webhook.

## Результаты

Локально пройдена цепочка NAME → GROUP → CONFIRM → NAME. Тесты проверяют пустой ввод, неверное подтверждение, отказ, отмену и независимость пользователей. Токен не предоставлен, поэтому реальная переписка в Telegram не проверялась.
