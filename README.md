## Подготовка

Нужен Python **3.10 или новее**. Основной код использует стандартную библиотеку. Из внешних пакетов нужны только `colorama` для требования ЛР по ООП и `behave` для BDD.

Linux и macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_checks.py
```

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run_checks.py
```

Если активация недоступна, вызывайте `.venv/bin/python` или `.venv\Scripts\python.exe` напрямую.

После подготовки перейдите в папку конкретной работы и используйте команды из её README. `run_checks.py` запускает все 30 модульных тестов и 6 BDD-сценариев в отдельных процессах.

## Особенности заданий

**РК 1.** Номер 17 определяет классы «Дирижёр» и «Оркестр». В исходном PDF не указано, какой буквенный набор соответствует этому номеру, поэтому доступны все наборы А, Б, В, Г, Д, Е. По умолчанию выводятся все 18 запросов. Один набор выбирается командой `python main.py --queries А` из папки РК 1. В условии набора А сортировка суммы показана по убыванию, остальные агрегаты отсортированы по возрастанию.

**Боты.** Режим `python main.py --demo` работает без сети. Для переписки в Telegram создайте бота через @BotFather и задайте `TELEGRAM_BOT_TOKEN` по инструкции в папке работы. Токены в репозиторий не добавляйте. Локальные диалоги и тесты выполнены; сетевые запуски и скриншоты переписки требуют собственного токена. У бота с автоматом данные находятся в памяти и исчезают при перезапуске.

**ДЗ.** Сделан небольшой проект на Python по выбранному пользователем языку. Исходное условие требует, чтобы язык был ранее неизвестен студенту. Отчёты оформлены по предоставленному образцу: Леонтьев Д.А., группа ИУ5-32Б, преподаватель Гапанюк Ю.Е. Интерпретатор и зависимости проверены в рабочем окружении; среду разработки на своём компьютере студент выбирает самостоятельно.

**Данные вакансий.** Оригинальный учебный набор включён в gzip без изменений. В папке функциональной работы выполните `python unpack_data.py`, затем `python -m lab_python_fp.process_data data_light.json`. Ссылка на источник и SHA256 приведены в `DATA_SOURCE.md`. Для короткого примера предусмотрен отдельный `data_demo.json`.

Полный протокол проверок всего репозитория: [CHECK_RESULTS.txt](CHECK_RESULTS.txt).
